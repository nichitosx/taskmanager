# Шрифт в поставке

`PxPlus_IBM_VGA_8x16.ttf` — шрифт текстового режима VGA из IBM PC: тот самый
экран DOS. На нём набран весь интерфейс, и выглядеть он должен одинаково на
любом компьютере, поэтому шрифт едет вместе с программой.

В нём есть всё, из чего собран терминальный вид: кириллица, блоки `█ ▄ ░ ▒ ▓`,
рамки `┌─┐│└┘ ═ ║ ╡ ╞`, треугольники `▲ ▼ ► ◄` и квадраты `■ □`.

Источник — The Ultimate Oldschool PC Font Pack, автор VileR, <https://int10h.org/oldschool-pc-fonts/>.
Распространяется по лицензии Creative Commons Attribution-ShareAlike 4.0
International: её текст лежит рядом, в `LICENSE-IBM-VGA.txt`. Файл не изменён.

Свой шрифт для заголовков кладётся не сюда, а в папку `fonts` рядом с
программой и выбирается в «Настройки → Общее → Шрифт».
