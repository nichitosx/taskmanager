# Шрифты приложения

Файлы `.ttf` и `.otf` из этой папки подключаются при запуске программы и
доступны только ей: устанавливать их в Windows не нужно, права администратора
тоже не требуются.

Пиксельное оформление ищет шрифт здесь в первую очередь. Положите сюда любой
пиксельный шрифт с кириллицей — например, свой файл шрифта Minecraft (обычно он
лежит в `%LOCALAPPDATA%\Microsoft\Windows\Fonts\` или `C:\Windows\Fonts\`).
Проще всего сделать это кнопкой «Настройки → Общее → Пиксельный шрифт →
Добавить файл…».

Готовых шрифтов в поставке нет намеренно: шрифт Minecraft — ресурс игры, его
распространение правообладатель не разрешает. Свой файл на своём компьютере
использовать можно.

Сами файлы шрифтов в репозиторий не попадают (см. `.gitignore`), поэтому при
обновлении программы они остаются на месте.
