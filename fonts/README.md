# Шрифты приложения

Файлы `.ttf` и `.otf` из этой папки подключаются при запуске программы и
доступны только ей: устанавливать их в Windows не нужно, права администратора
тоже не требуются.

Готовых шрифтов в поставке нет. Скачайте любой пиксельный шрифт с кириллицей и
положите файл сюда — или, что проще, добавьте его кнопкой
«Настройки → Общее → Пиксельный шрифт → Добавить файл…».

Что подойдёт:

* **Tiny5** и **Handjet** — бесплатные, с кириллицей, есть на fonts.google.com.
* **Pixeloid** — бесплатный, ищется по названию на dafont.com.
* Свой файл шрифта **Minecraft**, если он у вас уже установлен: обычно лежит в
  `%LOCALAPPDATA%\Microsoft\Windows\Fonts\` или `C:\Windows\Fonts\`.

Распространять чужие файлы шрифтов вместе с программой нельзя, поэтому их здесь
и нет. Сами файлы в репозиторий не попадают (см. `.gitignore`) и при обновлении
программы остаются на месте.

Если шрифта нет, программа не ломается: пиксельный стиль просто использует
обычный моноширинный шрифт.
