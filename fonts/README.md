# Шрифты приложения

Файлы `.ttf` и `.otf` из этой папки подключаются при запуске программы и
доступны только ей: устанавливать их в Windows не нужно, права администратора
тоже не требуются.

Весь интерфейс набран шрифтом IBM VGA 8×16 — он едет с программой и лежит в
`taskmanager/assets/fonts`. Здесь — шрифты для заголовков: название программы
и задачи в карточке можно набрать своим. Скачайте любой пиксельный шрифт с
кириллицей и положите файл сюда — или, что проще, добавьте его кнопкой
«Настройки → Общее → Шрифт заголовков → Добавить файл…».

Что подойдёт:

* **Tiny5** и **Handjet** — бесплатные, с кириллицей, есть на fonts.google.com.
* **Pixeloid** — бесплатный, ищется по названию на dafont.com.
* Свой файл шрифта **Minecraft**, если он у вас уже установлен: обычно лежит в
  `%LOCALAPPDATA%\Microsoft\Windows\Fonts\` или `C:\Windows\Fonts\`.

Свои файлы при обновлении программы остаются на месте. Если своего шрифта нет,
заголовки набираются тем же IBM VGA.
